Sobre

Musical Trainer é uma ferramenta de treino auditivo. Identifica intervalos, escalas e acordes tocando no teclado virtual ou num controlador MIDI físico.

Como funcionar

  • Praticar — ouve e toca as notas. Sem pontuação.
  • Iniciar sessão — os resultados contam.
  • Progresso — vê a evolução por tipo.

Perguntas frequentes

A prática conta para o progresso?
Não. O modo prática é efémero — nada é guardado quando sais.
Posso usar teclado MIDI físico?
Sim, se o browser suportar Web MIDI API (Chrome/Edge).
